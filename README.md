**DotNetProjectPractice** is a .NET-based learning repository that demonstrates software **design patterns, SOLID principles, CQRS, Saga orchestration, 
Repository Pattern, Strategy Pattern, and ASP.NET Core Web API development**. The solution provides **practical implementations** of **enterprise application 
architecture concepts**, helping developers build scalable, maintainable, and loosely coupled systems.

| Project           | Description                                                                                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| CQRS-Pattern      | Demonstrates Command Query Responsibility Segregation (CQRS) to separate read and write operations for improved scalability and maintainability. |
| RepositoryPattern | Implements the Repository Pattern to abstract data access logic and promote loose coupling between business and persistence layers.              |
| SagaPattern       | Illustrates the Saga Pattern for managing distributed transactions and ensuring data consistency across microservices.                           |
| SingletonPattern  | Demonstrates the Singleton Pattern to ensure a single instance of a class throughout the application's lifecycle.                                |
| SolidPrinciple    | Practical examples of all SOLID principles to create maintainable, extensible, and testable software solutions.                                  |
| StrategyPattern   | Shows how the Strategy Pattern enables dynamic selection of business algorithms at runtime without modifying client code.                        |
| WebApi            | ASP.NET Core Web API implementation following clean architecture, dependency injection, and RESTful design principles.      

**Architecture-Focused**
A **centralized solution** showcasing modern software architecture and design principles, including SOLID, CQRS, Saga Pattern, Repository Pattern, 
Strategy Pattern, and RESTful Web APIs to promote scalable, maintainable, and loosely coupled applications.|
